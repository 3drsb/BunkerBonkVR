# Rohan's Assets - Assignment 2

## Overview
This folder contains all 3D assets created for Bunker Bonk VR Assignment 2.

## Assets Included:
- Textured modular wall system
- Textured elevator kit
- New modular pieces (corners, ceiling, floor)
- Environmental props
- Optimization files

## Technical Specs:
- Software: Maya (modeling), Substance Painter (texturing)
- Format: .fbx
- Textures: PBR workflow (1024x1024)
- Optimised for Meta Quest VR
